# Zoe Frazer-Klotz — Freelancer Jekyll website

Live site: https://zo-klo.github.io

This uses [jeromelachaud/freelancer-theme](https://github.com/jeromelachaud/freelancer-theme) directly with GitHub Pages’ built-in Jekyll support. There is no custom Node build or hosted content editor.

## Edit content

Open a file, click the pencil icon, edit, and choose **Commit changes**. Changes to `main` publish automatically through GitHub Pages.

| What to change | File |
| --- | --- |
| Your name and the tagline beneath it | [_config.yml](_config.yml), `title` and `skills` |
| Your bio | [content/about.md](content/about.md) |
| Publications and manuscript in revise and resubmit | [content/publications.md](content/publications.md) |
| Theses and PDF/repository links | [content/Theses.md](content/Theses.md) |
| NLP analysis project | [content/project-sentiment-analysis.md](content/project-sentiment-analysis.md) |
| Measurement Matcher project | [content/project-measurement-matcher.md](content/project-measurement-matcher.md) |
| Weekly survey reporting automation | [content/project-weekly-report-automation.md](content/project-weekly-report-automation.md) |
| Contact text and links | [content/contact.md](content/contact.md) |
| Social icons in the footer | [_config.yml](_config.yml), `social` |

Use blank lines between paragraphs, `**bold**`, `*italics*`, and `[link text](https://example.com)`. Create a separate branch when committing if you want to keep a change as a draft until you merge it.

## Change colors later

The theme’s original palette is unchanged. In `_config.yml`, edit `color.primary` (teal), `color.secondary` (navy), and `color.secondary-dark` (dark footer). Values are hex codes without `#`. Update `primary-rgb` to match the primary color; it controls the project hover overlay. No layout changes are needed.

## Structure

`_includes/` and `_layouts/` contain the original theme templates plus the portfolio’s content sections. `style.css` is generated by Jekyll from the theme CSS. `custom.css` contains only portrait cropping, content spacing, and accessibility adjustments. The original license is retained in `LICENCE`.

GitHub Pages is configured to build from the root of `main` with Jekyll. For local development, install Ruby and Bundler, run `bundle install`, then `bundle exec jekyll serve`.
